# 🎓 ADS UNIFESO 2026

Site oficial da turma de Análise e Desenvolvimento de Sistemas — UNIFESO 2026.

O objetivo do projeto é centralizar informações importantes da turma e servir como ambiente colaborativo de desenvolvimento.

---

## ✨ Funcionalidades

- 📅 Calendário de eventos, provas e lives 
- 📖 Anuário da turma 
- 📂 Seção de documentos do curso 
- 💡 Iniciativas e projetos dos alunos

---

## 🛠 Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- ESLint
- Prettier
